# Set time window

Sets the time window to be used by R5.

## Usage

``` r
set_time_window(r5r_network, time_window)
```

## Arguments

- r5r_network:

  A routable transport network created with
  [`build_network()`](https://ipea.github.io/r5r/dev/reference/build_network.md).

- time_window:

  A number.

## Value

Invisibly returns `TRUE`.
